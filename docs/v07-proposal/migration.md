# 0.6 → 0.7 Migration Reference

All **46 verified breaking changes** (34 Python + 12 C++ Core). Old 0.6 forms are removed without deprecation shims.

> [!TIP]
> For interactive filtering and search, see the live preview site: https://symusic-v07-lyk.edge.randallflare.com/migration

## Python 0.6 → 0.7 (34 Changes)

| Severity | Category | 0.6 | 0.7 | Notes |
|---|---|---|---|---|
| Breaking | Imports & Types | `from symusic.core import NoteTick` | `from symusic import EventList, Note, Tick` | `symusic.core` becomes private `symusic._core`; `symusic.factory` and `symusic.types` are removed. Annotate with `Note[Tick]` and `EventList[Note[Tick]]`. |
| Breaking | Imports & Types | `ttype="tick"`<br>`TimeUnit.tick / TimeUnit.from_str(s)` | `ttype=Tick` | `ttype` is keyword-only and takes non-instantiable marker classes `Tick`, `Quarter`, or `Second`. Map config strings via `{"tick": Tick, "quarter": Quarter, "second": Second}[s]`. Calling `Score[Second]()` raises `TypeError`. |
| Breaking | Constructors & I/O | `Score(960)`<br>`Score.from_tpq(960)` | `Score(ticks_per_quarter=960)` | `Score(...)` constructs purely in memory with keyword-only arguments (defaults to `ticks_per_quarter=960`, `ttype=Tick`). |
| Breaking | Constructors & I/O | `Score(path)` | `Score.from_file(path)` | Eliminates polymorphic `Score(x)` guessing between file path, TPQ integer, and copy/convert. |
| Renamed | Constructors & I/O | `Score.from_file(path, fmt=..., sanitize_data=True)` | `Score.from_file(path, format=..., strict=False)` | `fmt` -> `format`; `strict=True` (default) rejects MIDI data bytes > 127, while `strict=False` clamps them to 127. Binary streams require explicit `format`. |
| **Silent trap** | Constructors & I/O | `Score(other)`<br>`Score.from_other(other, ttype)` | `other.to(Tick)  # or other.copy()`<br>`other.to(ttype)` | Silent 0.6 quirk: `Score(other)` converted `Quarter`/`Second` scores to `Tick` by default. Use `other.to(ttype)` to convert or `other.copy()` to preserve `ttype`. |
| Renamed | Constructors & I/O | `Score.from_midi(data, sanitize_data=True)`<br>`Score.from_abc(abc=text)` | `Score.from_midi(data, strict=False)`<br>`Score.from_abc(text)` | All readers (`from_file`, `from_midi`, `from_abc`) take `strict=True` by default; pass `strict=False` to clamp out-of-range MIDI data bytes. |
| Renamed | Constructors & I/O | `score.dumps_midi()`<br>`score.dumps_abc()` | `score.to_midi()`<br>`score.to_abc()` | Symmetric with `Score.from_midi()` and `Score.from_abc()`. |
| Renamed | Constructors & I/O | `score.dump_midi(path)`<br>`score.dump_abc(path)` | `score.to_file(path)` | Unified file and binary-stream writer (pass `format="abc"` if extension is not `.abc`). Binary streams require explicit `format`, remain caller-closed, and handle short writes. |
| Renamed | Constructors & I/O | `score.tpq` | `score.ticks_per_quarter` | Spelled out everywhere. Retained on `Quarter`/`Second` scores as metadata for `.to(Tick)` and MIDI export (`1..32767`). |
| Renamed | Events & Pedals | `score.note_num()`<br>`track.note_num()` | `score.note_count()`<br>`len(track.notes)` | `Track` drops `note_num()` in favor of standard `len(track.notes)`; `Score` spells it out as `note_count()`. |
| Renamed | Operations & CQS | `score.get_beats(start_time=0)`<br>`score.get_downbeats(start_time=0)` | `score.beats(start=0)`<br>`score.downbeats(start=0)` | Drops redundant `get_` prefix and shortens `start_time` to `start`. |
| Renamed | Events & Pedals | `x.empty()` | `x.is_empty()` | Consistent predicate naming across `Score`, `Track`, and `EventList`. For lists, `not notes` also works. |
| Renamed | Operations & CQS | `score.to(ttype, min_dur=...)` | `score.to(ttype, min_duration=...)` | `min_duration` is spelled out and keyword-only. |
| Breaking | Operations & CQS | `score.resample(tpq=480, min_dur=...)` | `score.resample(480, min_duration=...)` | Returns `Score[Tick]` quantized directly to the target grid in one step (avoiding double rounding on `Quarter`/`Second` scores); `min_duration` is keyword-only. |
| Breaking | Operations & CQS | `notes.sort(key, True)` | `notes.sort(key=key, reverse=True)` | `key` and `reverse` are keyword-only on lists. `Score.sort()` and `Track.sort()` sort all contained event lists by default keys while keeping `Score.tracks` in order. |
| **Silent trap** | Operations & CQS | `y = x.shift_pitch(2)`<br>`x.shift_time(d, inplace=False)` | `y = x.copy()`<br>`y.shift_pitch(2)` | Silent trap: `sort`, `shift_time`, `shift_pitch`, and `shift_velocity` now mutate in place and return `None`. Writing `y = x.shift_pitch(2)` mutates `x` and sets `y = None`! |
| **Silent trap** | Operations & CQS | `x.clip(..., inplace=True)`<br>`x.adjust_time(...)` | `x = x.clip(...)`<br>`x = x.adjust_time(...)` | Element-dropping transforms (`clip`, `trim`, `adjust_time`, `filtered`) always return a new independent object and leave the source unchanged. Ignoring the return value is a silent no-op. |
| Breaking | Operations & CQS | `notes.filter(f)` | `track.notes = track.notes.filtered(f)` | Renamed to `filtered(f)` returning a new deep-copied `EventList`. To mutate in place through aliases, use `notes[:] = [n for n in notes if f(n)]`. |
| Breaking | Operations & CQS | `x.copy(deep=False)` | `copy.copy(x)` | `.copy()` is always deep and compacts into a single contiguous chunk via `pyvec::compact()` (Python omits a separate `contiguous()` API); use stdlib `copy.copy(x)` for shallow copies. Copy constructors (`Score(other)`, `Note(other)`) are removed. |
| Breaking | Events & Pedals | `Track.empty(ttype)`<br>`Track(..., pedals=...)` | `Track(ttype=Tick, controls=[...])` | `Track(...)` replaces `Track.empty()`. Stored `pedals` are removed; encode sustain as CC64 `ControlChange` pairs in `controls`. |
| **Silent trap** | Events & Pedals | `track.pedals` | `track.pedals()` | Changed from a stored list to a method returning a detached tuple derived from CC64 in `track.controls`. Watch out: `clip`/`trim` filter controls by timestamp, which can split boundary pedals. |
| **Silent trap** | Events & Pedals | `NoteTick(t, d, p)` | `Note(t, d, p)  # velocity=64` | Silent behavior change from old core bindings: omitted `velocity` now defaults to `64` (MIDI 1.0 recommended default `0x40`, matching `mido` and `muspy`) instead of `0`. |
| Renamed | Events & Pedals | `Note.start / Pedal.start`<br>`note.end_time() / ent_time()` | `note.time / pedal.time`<br>`note.end` | Removes duplicate `start`/`time` aliases and the legacy `end_time()`/`ent_time()` typo methods. |
| Renamed | Events & Pedals | `TextMeta(time, text)` | `TextEvent(time, text)` | Renamed for clarity across lyrics and markers. Calling `to_numpy()` on `EventList[TextEvent[T]]` raises `TypeError`. |
| Renamed | Events & Pedals | `Tempo(t, mspq=...)`<br>`tempo.mspq / tempo.tempo` | `Tempo(t, qpm)`<br>`.qpm / .microseconds_per_quarter` | Accepts `qpm` or `microseconds_per_quarter=...` (passing both raises `ValueError`). `Tempo.__match_args__` is `("time", "qpm")`. |
| Breaking | Events & Pedals | `KeySignature(t, key, tonality)`<br>`ks.tonality` | `KeySignature(t, key, minor)`<br>`ks.minor: bool` | Replaces numeric `tonality` (0/1) with an explicit boolean `minor` field. |
| **Silent trap** | NumPy & SoA | `notes.numpy()`<br>`Note.from_numpy(...)` | `notes.to_numpy()`<br>`EventList.from_numpy(Note, **cols)` | Silent trap: `pitch` and `velocity` are now `uint8` (matching `ControlChange` and `pianoroll`) — cast to `int16` before `np.diff` to avoid unsigned underflow! Columns renamed: `mspq` -> `microseconds_per_quarter`, `tonality` -> `minor`. |
| Breaking | Synthesis & SoundFont | `Synthesizer(sf_path=None, quality=...)` | `Synthesizer(path_to_sf2_or_sf3)`<br>`Synthesizer(download_soundfont())` | FluidSynth replaces `prestosynth` inside the wheel. Requires a local SF2/SF3 path or one-click `download_soundfont()`; `quality` is removed. |
| **Silent trap** | Synthesis & SoundFont | `synth.render(score, True)` | `synth.render(score, stereo=True)` | Silent shape trap: audio output transposed from `(channels, samples)` to float32 `(frames, channels)` (mono is `(frames, 1)`), and `stereo` is keyword-only. |
| **Silent trap** | Synthesis & SoundFont | `symusic.dump_wav(path, audio, rate)` | `scipy.io.wavfile.write(path, rate, audio)` | `dump_wav` is removed. Watch out: passing float32 audio directly to `scipy.io.wavfile.write` writes IEEE float32 WAV unless you explicitly clip and scale to `int16`. |
| Breaking | Synthesis & SoundFont | `BuiltInSF3.MuseScoreGeneral().path()`<br>`BuiltInSF2.MuseScoreGeneral().path() / Soundfont` | `download_soundfont("musescore_general_sf3")`<br>`download_soundfont("musescore_general_sf2")` | Replaces `Soundfont`, `BuiltInSF2`, and `BuiltInSF3` with a single `download_soundfont(name="musescore_general_sf3", *, cache_dir=None, force=False) -> Path` function (idempotent local cache + SHA-384 verification, preset IDs typed via `Literal[...]`). |
| **Silent trap** | Imports & Types | `notes == []`<br>`notes == [n1, n2]` | `not notes`<br>`list(notes) == [n1, n2]` | Silent trap: `EventList` and `TrackList` enforce strict `MutableSequence` equality (comparing `event_type`, `ttype`, and elements) and never implicitly equate against plain Python `list`. |
| **Silent trap** | Constructors & I/O | `pickle.loads(v06_score_bytes)` | `Score.from_midi(data)` | Pickles are for inter-process transport, not archival storage. 0.7 adds a versioned `SYMZ` v2 header and rejects incompatible 0.6 payloads. |

## C++ Core 0.6 → 0.7 (12 Changes)

| Severity | Category | 0.6 | 0.7 | Notes |
|---|---|---|---|---|
| C++ Core | C++ Core & Storage | `ScoreNative<Tick>`<br>`score.to_native() / to_shared()` | `Score<Tick>  // ValueStorage` | PR #131 (`include/symusic/storage.h`): Drops `pyvec` and `*Native` types from C++ core. Pure C++ uses `ValueStorage` (`vec<Track<T>>`); Python bindings supply `symusic::py::SharedStorage`. |
| C++ Core | C++ Core & Storage | `Score<Tick>::parse<DataFormat::MIDI>(bytes, true)` | `Score<Tick>::from_midi(`<br>`bytes, {.invalid_data_bytes = InvalidDataBytes::Clamp}`<br>`)` | PR #131, #134 (`score.h`, `io/midi.h`): Replaces template-enum + bool flag with `MidiReadOptions` and `InvalidDataBytes::{Raise, Clamp}` (default `Raise`); use `read_score<Tick>(path)` for files. |
| C++ Core | C++ Core & Storage | `score.dumps<DataFormat::MIDI>()` | `score.to_midi()` | PR #131, #134 (`score.h`, `io/iodef.h`): Direct format method prunes `DataFormat` to `MIDI` and `ABC` only; single-pass note-on/note-off merge delivers ~44% faster MIDI reading. |
| **Silent trap** | C++ Core & Storage | `score.dumps<DataFormat::ZPP>()`<br>`Score<Tick>::parse<DataFormat::ZPP>(bytes)` | `score.serialize()`<br>`Score<Tick>::deserialize(bytes)` | PR #129, #131, #134 (`io/iodef.h`, `detail/zpp_impl.h`): Prefixed with `SYMZ` + `kZppVersion=2`, zeroes struct padding, bounds allocations, validates bools, rejects trailing bytes. Incompatible with 0.6 payloads. |
| C++ Core | C++ Core & Storage | `track.pedals` | `auto pedals = track.pedals();` | PR #134 (`track.h`, `detail/track_impl.h`): Removes stored `pedals` field; `Track::pedals() const` derives closed sustain regions from CC64 controls on demand. |
| C++ Core | C++ Core & Storage | `score.sort_inplace()`<br>`score.clip_inplace(...) / deepcopy()` | `score.sort();`<br>`auto c = score.clip(...); score.copy();` | PR #134 (`score.h`, `track.h`, `ops.h`): All `*_inplace` methods removed. Mutators use transactional `detail::FieldUpdates`; `clip`/`trim` return copies (~40%/~30% faster via `copy_score_with_tracks`). |
| C++ Core | C++ Core & Storage | `Tempo<Tick>::qpm2mspq(120)`<br>`KeySignature(t, k, i8) / note_num()` | `Tempo<Tick>::qpm_to_microseconds_per_quarter(120)`<br>`KeySignature(t, k, bool) / note_count()` | PR #131, #134 (`event.h`, `detail/event_fields.h`, `score.h`, `track.h`): Constructors validate ranges via `checked_event_field<E, I>()` (`std::invalid_argument`); adds `set_ticks_per_quarter(i64)` and `set_program(i64)`. |
| C++ Core | C++ Core & Storage | `NoteArr<T>, PedalArr<T>, ... (8 *Arr)` | `EventColumns<Note<T>> cols(notes);` | PR #131, #134 (`soa.h`, `detail/event_fields.h`): Single descriptor-driven generic struct (`for_each(visitor)`) eliminates ~320 lines of boilerplate and drops `MetaMacro.h` from public headers. |
| C++ Core | C++ Core & Storage | `Synthesizer(sfPath, rate, quality)`<br>`-> psynth::AudioData` | `Synthesizer(lib_path, sf, SynthSettings{})`<br>`-> AudioBuffer` | PR #132, #134 (`synth.h`, `src/synth.cpp`): Runtime `dlopen`/`LoadLibraryExW` of FluidSynth for LGPL-2.1-or-later compliance; renders pitch bends, CC64 sustain, and controls with fresh state per call (up to 256 note-bearing tracks). |
| C++ Core | C++ Core & Storage | `read_file(path)`<br>`write_file(path, buf)` | `read_score_file(path)`<br>`score_file_format(path, format)` | PR #130, #133, #134 (`io/common.h`, `detail/file_error.h`, `src/io/common.cpp`): Rejects directories and non-regular files (FIFOs -> `ESPIPE`) and normalizes directory writes to `std::errc::is_a_directory`. |
| C++ Core | C++ Core & Storage | `ops::trim_inplace(events, ...)`<br>`ops::adjust_time(...)` | `ops::trim<S>(events, start, end, ...)`<br>`score.trim(start, end, ...)` | PR #129, #134 (`utils.h`, `ops.h`): `ops::trim<S>` operates on an event range (e.g. `track.notes`) while `Score` exposes `score.trim(...)`. Validates bounds, modes, and overlap; `detail::add_time`/`sub_time` check overflow. Note: C++ `ops::adjust_time` is still `void` in PR #134; copy semantics are a planned 0.7 follow-up. |
| C++ Core | C++ Core & Storage | `Linked prestosynth + pyvec`<br>`+ vendored include/argparse.h` | `find_package(symusic REQUIRED)`<br>`symusic::symusic (cxx_std_20)` | PR #131, #134 (`CMakeLists.txt`, `cmake/InstallCore.cmake`): Clean, self-contained C++20 library export without `prestosynth`, `pyvec`, or 2,184-line `include/argparse.h`. |
